# AppPages

Reusable, static privacy and support pages for portfolio apps. Published pages are under `apps/<app-slug>/support/` and `apps/<app-slug>/privacy/`; the site index links to every public page.

An app may also provide an optional landing page at `apps/<app-slug>/` for use as its App Store Marketing URL.

The templates are deliberately not app-specific legal claims. Unknown facts must remain an explicit TODO and be resolved before publication.

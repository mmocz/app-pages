Support & contact

Network Compass works on iPhone and iPad with iOS or iPadOS 17 or later.

Need help?

Email info@sdilejslunce.cz. Include your device model, iOS version, app version, the tool you used, and the steps that led to the problem. Share a screenshot or report only after removing private addresses, names, credentials or other information you do not want to send.

Start with your network

Connect to Wi-Fi, open Explore, allow Local Network access, and run a scan. Tap a device to inspect its addresses, advertised services, ports and observed details. Save a name or favorite to recognize it later. Settings → Explore a sample network lets you learn the interface without sending scan traffic.

A device is missing

Keep the device awake and on the same local network. Guest Wi-Fi, client isolation, firewalls and sleeping devices can block discovery. Check Local Network access in iOS Settings and run another scan. A device that does not respond is not proof that it is offline. Scans show observed evidence, not a complete security audit.

Wi-Fi and Bluetooth details

Wi-Fi identity requires Location permission and may require precise location. iOS does not expose a complete list of nearby Wi-Fi networks or radio frames to this app. Bluetooth discovery primarily shows Bluetooth LE advertisements; silent devices and accessories not advertising may be absent. Some system-connected accessories are visible through supported iOS interfaces.

Internet diagnostics and speed estimates

Enter a domain, IP address or URL in Tools. Use DNS, ping, traceroute, ports and HTTP/TLS checks to investigate a specific issue. Routers may suppress ping and intermediate traceroute replies. Transfer tests use data and report the connection observed during that run. iPerf requires an iPerf3 server you provide.

Optional server companion

Open Tools → VPS companion and connect this device if server capacity is available. You can compare phone and server checks, test public targets, and create server-side monitors. Local network tools work without the companion. The shared service has per-device and overall capacity limits; hosting availability and limits may change.

For notifications, enable push in the companion and allow notifications in iOS. Pausing a monitor stops its checks. Deleting a monitor removes its configuration. Revoking/disconnecting the device removes the associated server data and stops its monitors. Disconnect before uninstalling if you have active monitors. See the Privacy Policy for retention and deletion details.

Capture files, reports and hardware tools

Open an existing PCAP/PCAPNG file from Files to inspect it locally. The traffic screen also shows this app’s HTTP activity; it does not capture other apps’ traffic. NFC needs a supported iPhone and compatible tags. Phone-to-phone direction and distance need compatible Nearby Interaction hardware. Use network and tag tools only on systems you own or have permission to test.

Free app

Network Compass is free, with no ads, in-app purchases or subscription. No personal account is required. Optional internet services need a connection; the shared companion is subject to capacity limits.

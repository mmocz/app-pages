Subtle Markdown is being prepared for release. This guide describes the upcoming Mac app.

Start with a note

Choose File → New Note or open a Markdown file. Save a new note once to choose its location. After that, changes save automatically. Add a folder to the library to browse and search its Markdown files.

Where does my writing live?

Notes are ordinary Markdown files in the locations you choose. Subtle Markdown also keeps local recovery drafts and history in its application storage. A folder in iCloud Drive or another file provider follows that provider’s synchronization settings.

How do I format text or edit Markdown?

Use the Format menu for headings, emphasis, lists, links, images, tables, and code. Choose View → Toggle Markdown Source for direct source editing. Advanced Markdown that cannot be safely edited as rich text is shown as preserved source.

How do I recover writing?

Look for recovered drafts in the library and use History to preview earlier versions. Restoring a history item stages it for review; choose Save when you are ready. If another app changes an open file, Subtle Markdown keeps a conflict copy of your writing so you can compare both versions. Review the save message for the copy’s location.

Why are some images hidden?

Remote images are blocked by default. You can enable them in Settings, which allows the image hosts to receive requests. For portable notes, save the note first and insert a local image; Subtle Markdown copies it into an adjacent Assets folder. Keep that folder with the note when moving or sharing it.

Can I share a document with someone using Word?

Export Rich Text (Word Compatible) for a file Word can open, or export HTML. Use Print to save a PDF. HTML and rich-text exports include accessible adjacent local images and omit remote images. Review the result before sharing, especially documents with advanced Markdown.

What if saving fails?

Keep the app open, check the save message, and use Save As to make another copy in a writable folder. Make sure the disk has space and your file provider is available. Avoid deleting recovery data while troubleshooting.

Help us understand the problem

In a support email, include the app version, macOS version, what you expected, and the steps that led to the problem. A small, non-confidential example is helpful. Review screenshots and attachments before sending them; your notes are not automatically included in a support request.
